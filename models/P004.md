# iDRO (BiLSTM-CRF + RNA-Bart)

P004 · CDS and full mRNA design

**Paper:** Integrated mRNA sequence optimization using deep learning

https://doi.org/10.1093/bib/bbad001

**Task:** Optimize codons and generate matching UTRs for an input protein

**Method:** BiLSTM-CRF performs codon tagging with contextual and neighboring-tag information; RNA-Bart is an attention-based encoder-decoder generating UTRs from ORF.

**Inputs:** Amino acid sequence; ORF for UTR generator

**Outputs:** CDS and generated 5′/3′ UTRs
