# mRNAdesigner

P015 · CDS and full mRNA design

**Paper:** mRNAdesigner: an integrated web server for optimizing mRNA design and protein translation in eukaryotes

https://doi.org/10.1093/nar/gkaf410

**Task:** Optimize CDS and select UTR modules for translation

**Method:** Highest-frequency synonymous codons initialize search; Monte Carlo tree search/UCB explores substitutions using CAI, GC, unpaired ratio and stem constraints. Curated 5′/3′ UTR libraries complete design.

**Inputs:** CDS, host species and optimization priorities

**Outputs:** Full sequence candidates
