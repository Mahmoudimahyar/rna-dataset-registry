# Translation efficiency covariation (TEC)

P009 · Translation regulation and dynamics

**Paper:** Translation efficiency covariation identifies conserved coordination patterns across cell types

https://doi.org/10.1038/s41587-025-02718-5

**Task:** Find coordinated translation patterns across cell types

**Method:** Quality-controlled public datasets are processed into TE using compositional regression; proportionality measures gene-pair covariation; enrichment/association and clustering identify conserved coordination.

**Inputs:** Paired Ribo-seq/RNA-seq TE estimates for genes and cell types

**Outputs:** TEC proportionality network; associations with function/protein interactions
