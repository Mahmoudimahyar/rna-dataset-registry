# Optimus 5-Prime

P002 · 5′UTR and translation initiation

**Paper:** Human 5′ UTR design and variant effect prediction from a massively parallel translation assay

https://doi.org/10.1038/s41587-019-0164-5

**Task:** Predict mean ribosome load (MRL) and design UTRs for target loading

**Method:** Three convolutional layers plus dense output learn motifs/context; a genetic algorithm mutates and selects sequences using the predictor.

**Inputs:** One-hot 50-nt randomized 5′ UTR

**Outputs:** MRL or 14-fraction polysome profile; optimized UTR
