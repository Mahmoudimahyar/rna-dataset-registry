# UTR-Insight

P019 · 5′UTR and translation initiation

**Paper:** UTR-Insight: integrating deep learning for efficient 5′ UTR discovery and design

https://doi.org/10.1186/s12864-025-11269-7

**Task:** Predict MRL, screen natural UTRs and design synthetic UTRs

**Method:** UTR-LM embeddings feed Conv-Former CNN/self-attention layers; frame pooling aligned to start codon handles length/frame; genetic algorithm uses predictor for design.

**Inputs:** Variable-length 5′ UTR

**Outputs:** MRL prediction and candidate UTR
