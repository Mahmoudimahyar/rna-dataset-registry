# Riboformer

P049 · Translation regulation and dynamics

**Paper:** Riboformer: a deep learning framework for predicting context-dependent translation dynamics

https://doi.org/10.1038/s41467-024-46241-8

**Task:** Predict codon-resolved ribosome density and identify sequence-dependent stalling.

**Method:** Transformer captures contextual codon dependencies; an unbiased training set supports artifact correction, while in-silico mutagenesis identifies stalling motifs across biological states.

**Inputs:** Codon context and ribosome-profiling training data.

**Outputs:** Predicted ribosome-density profiles and inferred experimental-bias corrections.
