# mRNA Expression Wizard / random-forest models

P026 · CDS and full mRNA design

**Paper:** Revealing determinants of translation efficiency via whole-gene codon randomization and machine learning

https://doi.org/10.1093/nar/gkad035

**Task:** Explain and predict expression differences among synonymous coding sequences.

**Method:** Compares several ML approaches and sequence regions; a random forest using only the first eight codons achieves Pearson r=0.762. Analysis implicates start-region structure over whole-CDS CAI.

**Inputs:** Sequence features from whole-gene randomized red fluorescent protein variants in E. coli.

**Outputs:** Predicted protein production and feature importance.
